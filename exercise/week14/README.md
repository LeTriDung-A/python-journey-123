## Noi dung

- Class va object.
- `__init__`, `self`, instance attributes va methods.
- `__str__`.
- Composition: `Student` co mot danh sach `Course`.
- Inheritance don gian: `SavingsAccount` la mot `BankAccount`.

Vi du giu code don gian de tap trung vao cach mo hinh hoa doi tuong.
